CITY SHROUDED IN SHADOW — versao 1.0 / version 1.0

PORTUGUES
Esta pasta nao inclui o jogo, firmware, saves ou recursos extraidos.
Requer Windows 10/11 x64, CPU com AVX2, placa/driver Vulkan e disco NTFS
ou exFAT com espaco para uma copia do seu dump e arquivos temporarios.

1. Extraia o ZIP inteiro para uma pasta onde voce possa gravar.
2. Abra City Shrouded in Shadow.exe e escolha Preparar jogo.
3. Selecione o dump do seu proprio disco: CUSA03562, versao 01.03.
4. Selecione os modulos do sistema extraidos do seu proprio PS4.
5. Aguarde a preparacao. Escolha portugues, ingles ou japones e jogue.

Nenhum jogo ou firmware e baixado. Nao mova as pastas internas.
A preparacao usa uma copia do dump; nao altera os arquivos de origem.
Saves, configuracoes e logs ficam em data/. Preserve essa pasta ao atualizar.

PROBLEMAS CONHECIDOS: o desempenho varia conforme o computador; a campanha
inteira ainda nao foi jogada do inicio ao fim no PC. Alguns nomes de lugar no
minimapa podem ser cortados na borda. Linux usa Wine/umu e exige verificacao
propria. O codigo-fonte correspondente acompanha esta versao (ZIP de fontes).

ENGLISH
This folder contains no game, firmware, saves or extracted game assets.
Requires Windows 10/11 x64, AVX2 CPU, Vulkan GPU/driver and an NTFS/exFAT
drive with room for a copy of your owned dump and temporary setup files.
Extract the complete ZIP, open City Shrouded in Shadow.exe, select Prepare
game and provide your own CUSA03562 v01.03 dump and PS4 system modules.
Choose English, Brazilian Portuguese or Japanese after setup finishes.
No game or firmware is downloaded. Saves/settings/logs stay in data/.

Known issues: performance varies; the full campaign has not been played start
to finish on PC. Some minimap place names may be clipped at the edge. Linux
uses Wine/umu and needs its own checks. Matching source code is published
with this release (source ZIP).
See licenses/ for the notices already collected.
